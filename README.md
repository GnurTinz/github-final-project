# Simple Interest Calculator

A simple Bash-based project to calculate simple interest.

## Description

This project calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal**: The initial amount of money.
- **Rate**: The annual rate of interest in percent.
- **Time**: The time period in years.

## Usage

Run the Bash script:

```bash
bash simple-interest.sh
```

Enter the principal amount, rate of interest, and time period when prompted.

## Example

- Principal: 1000
- Rate of interest: 5%
- Time: 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100
